# وَرّاق — محرر ونظام صف وتأليف الكتب العربية (Warraq)

محرر ونظام صف كتب رقمي مخصص لمؤلفي الكتب العربية غير الروائية (الدراسات والأبحاث وأمهات الكتب). يتيح لك الكتابة مباشرة على صفحات الكتاب الحقيقية بمقاساتها المطبعية الفعلية وهوامشها المتقابلة وكعب التجليد، بدلاً من محررات النصوص التقليدية.

---

## المميزات الرئيسية للمؤلف

1. **الكتابة على صفحات الكتاب الفعلية (Physical Book Spread)**:
   - عرض **مفردتين متقابلتين (Two-Page Spread)** مع كعب التجليد وظلال انحناء الورق وعمق الورق المرصوف.
   - مقاس **القطع الوزيري الكلاسيكي ($17 \times 24$ سم)** المعتمد في دور النشر العربية لأمهات الكتب والدراسات.
   - خيارات إضافية للقطع: **الحجم المتوسط ($14 \times 21$ سم)**، **مقاس A5 الدولي**، **المجلد الموسوعي ($20 \times 27$ سم)**، و**كتاب الجيب ($11.5 \times 18$ سم)**.

2. **هوامش الطباعة المتقابلة (Alternating Recto/Verso Margins)**:
   - **الصفحة اليمنى (Recto / فردية)**: هامش الكعب (Gutter) على اليسار، وهامش الإبهام الخارجي على اليمين مع رقم الصفحة وترويسة الفصل.
   - **الصفحة اليسرى (Verso / زوجية)**: هامش الكعب على اليمين، وهامش الإبهام على اليسار مع عنوان الكتاب ورقم الصفحة.

3. **نظام حواشي وتوثيق مدمج (Footnotes Engine)**:
   - اختصار سريع `Alt + F` لإدراج رقم إحالة في المتن ونقلك مباشرة إلى الحاشية أسفل الصفحة.
   - خط فصل الحواشي التراثي (Footnote rule) وتنسيق الإحالات تلقائياً بالأرقام المشرقية `(١)، (٢)` أو المغربية `(1)، (2)`.

4. **طباعة فاخرة وأدوات نصوص تراثية**:
   - خطوط طباعية عربية مدمجة بالكامل: **أميري (Amiri)** الكلاسيكي المأخوذ من مطبعة بولاق، و**شهرزاد الجديد (Scheherazade New)**.
   - إدراج **أقواس الآيات القرآنية المزهرة `﴿ ﴾`** بلون زمردي مخصص.
   - إدراج **علامات التنصيص العربية « »**.
   - قائمة رموز التبجيل والتصلية: `ﷺ`، `رضي الله عنه`، `عليه السلام`، `جل جلاله`، `رحمه الله`.
   - خامات ورق الكتاب: **ورق شمواه (Munken Cream)**، **ورق عاجي**، **ورق أبيض مطبعي**، **ورق تراثي**.

5. **فهرس الفصول وحفظ المخطوطة**:
   - لوحة جانبية لإدارة الفصول والأبواب والبيانات الوصفية (المؤلف، العنوان، دار النشر، سنة الطبع).
   - إحصاءات حية: عدد الصفحات، الكلمات، الحروف، عدد الهوامش، وزمن القراءة التقديري.
   - حفظ تلقائي فوري في المتصفح، مع إمكانية تصدير واستيراد المخطوطة بصيغة JSON.

6. **تصدير مباشر للطباعة (PDF)**:
   - تصدير مباشر إلى PDF مطابق تماماً لأبعاد القطع بالمليمترات بدون أي هوامش متصفح إضافية، جاهز للإرسال للمطابع التجارية.

## التشغيل والتطوير

```bash
# تثبيت الاعتماديات
pnpm install

pnpm dev

# فحص الأكواد والجودة
pnpm lint

# تشغيل الاختبارات المؤتمتة
pnpm test

# بناء حزمة الإنتاج
pnpm build
```
